# Telegram-бот заявок

Пользователь выбирает тип обращения, вводит ФИО и описание идеи или вопросов для встречи. Бот отправляет заявку в указанную группу и показывает подтверждение.

## Настройка и запуск

1. Создайте бота через @BotFather и добавьте его в группу администраторов с правом отправлять сообщения.
2. Заполните `.env`: `BOT_TOKEN` — токен бота, `ADMIN_CHAT_IDS` — числовой ID группы (обычно начинается с `-100`). Можно указать несколько ID через запятую. Это ID чатов назначения, а не список прав администраторов.
3. Запустите `docker compose up --build -d`. Логи: `docker compose logs -f bot`. Остановка: `docker compose down`.

Бот не запускается с пустыми `BOT_TOKEN` или `ADMIN_CHAT_IDS`: это сделано, чтобы ошибка настройки обнаруживалась сразу, а не при первой заявке.

`app/domain` содержит модели и проверку ФИО, `app/application` — сценарий отправки, `app/infrastructure/telegram` — обработчики и интеграцию с Telegram, `app/config` — настройки.

Валидация допускает русские и английские буквы, пробелы, дефисы и апострофы внутри слов, но не может гарантировать подлинность ФИО. Состояние незавершённой заявки хранится в памяти и сбрасывается при перезапуске.
